# Nivi's First Project - ShopHub E-commerce Website

I'm creating a fully functional e-commerce website called **ShopHub**!

## 📋 Features

### Core E-commerce Features
- **Product Display**: Browse products organized by categories (Electronics, Fashion, Books)
- **Shopping Cart**: Add/remove items, view cart total
- **Product Filtering**: Filter products by category
- **Cart Persistence**: Cart data is saved to local storage
- **Responsive Design**: Works great on desktop and mobile devices

### Website Sections
1. **Navigation Bar**: Logo, menu links, and shopping cart icon with item count
2. **Hero Section**: Eye-catching banner with call-to-action
3. **Products Section**: Product grid with filtering by category
4. **About Section**: Information about ShopHub
5. **Contact Section**: Contact form for customer inquiries
6. **Shopping Cart Modal**: View and manage cart items
7. **Footer**: Copyright and credits

## 🛠️ Technologies Used
- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with flexbox and grid layout
- **Vanilla JavaScript**: Shopping cart functionality, product filtering, notifications

## 🚀 How to Use
1. Open `index.html` in your web browser
2. Browse products and use filters to find items by category
3. Click "Add to Cart" to add items to your shopping cart
4. Click the shopping cart icon (🛒) to view your cart
5. Proceed to checkout or continue shopping
6. Use the contact form to reach out

## 💾 Data Persistence
All cart items are saved to your browser's local storage, so your cart will persist even if you refresh the page!
